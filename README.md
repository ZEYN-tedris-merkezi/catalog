# ZEYN Kataloq 2026 - GitHub Pages

Bu paket tam kataloq PDF-si ilə hazırdır.

## Yükləmə
1. GitHub-da `catalog` adlı public repository yaradın.
2. ZIP-dəki bütün faylları repository-nin əsas qovluğuna yükləyin.
3. Settings -> Pages bölməsində:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
4. Save edin.

Sayt ünvanı:
https://zeyn-tedris-merkezi.github.io/catalog/

QR kod həmin ünvana aparır. PDF sonradan yenilənəndə faylın adını `Kataloq-2026.pdf` saxlayın; QR dəyişməyəcək.
